# A2 — First five complete topics

The first preview slice follows the progression of Krížom-krážom: Slovenčina A2, lessons 1–5, while using original SK/UA explanations, examples and exercises.

1. Program sa začína — Rodinný duel / Slovensko — possessive pronouns; adjective models pekný/cudzí.
2. Čo radi robíte? — Voľný čas — rád/rada/radi; deverbal nouns and related verb patterns.
3. Vianoce u nás doma — Rodina / Vianoce — adjective comparison; Dative and Dative prepositions.
4. Cestovať je dobrodružstvo — Cestovanie — adverbs vs adjectives; relative clauses; lebo/preto; conditional.
5. U lekára — Ľudské telo / Zdravie — Genitive; verbs and prepositions with Genitive; Genitive pronouns.

Each topic currently includes:
- 6 bilingual vocabulary cards with original example sentences
- one focused visual grammar concept
- RULE and TIP blocks
- one interactive practice item
- explicit wrong-answer explanation tied back to the grammar rule

This is a vertical-slice preview. Vocabulary volume, exercise variety, spaced review and additional visual grammar panels will be expanded after validating the experience.
