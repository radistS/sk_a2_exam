# A2 Exam Skills

This directory contains the five canonical exam-preparation skill areas used by the application.

1. `reading` — Čítanie s porozumením
2. `listening` — Počúvanie s porozumením
3. `language-use` — Lexika a gramatika
4. `writing` — Písanie
5. `speaking` — Ústny prejav a komunikácia

These are preparation categories for the trainer. They provide a stable internal curriculum model even when the exact grouping, naming, timing or scoring of exam sections differs between authorized examination providers.

Each skill will contain its own original practice tasks and may reference grammar/vocabulary topics elsewhere in `content/`.

## Planned first task families

- Reading: notices, messages, e-mails, short practical texts, true/false and multiple choice.
- Listening: short dialogues and announcements with comprehension questions. Audio infrastructure is deferred; transcripts can be authored first.
- Language use: gap filling, multiple choice, morphology, prepositions, cases, verb forms and everyday vocabulary.
- Writing: short message/e-mail, practical request, invitation/reply, simple description.
- Speaking: personal introduction, everyday questions, situational dialogue, picture/situation description.

Mock exams should compose tasks from these skills according to `docs/EXAM_SPEC.md` and the verified target-provider profile.
